SISTEMA 01

Iluminação automática por presença

Um sensor de presença combinado a um sensor de luz decide acender o LED — economizando energia ao não ligar a luz quando o ambiente já está claro.

Como funciona

O sensor PIR detecta movimento de pessoas na área monitorada, enquanto o LDR (sensor de luminosidade) mede o quanto de luz existe no ambiente. O Arduino só liga o LED quando as duas condições de "ambiente escuro" e "pessoa presente" acontecem ao mesmo tempo — exatamente como um sensor de presença de corredor.

  • PIR (pino 2): detecta movimento (HIGH/LOW)
  • LDR (pino A0): lê a luminosidade (0–1023)
  • LED (pino 13): saída controlada

const int led = 13;
const int pir = 2;
const int ldr = A0;

int limiteLuz = 500; 

void setup() {

  pinMode(led, OUTPUT);
  pinMode(pir, INPUT);

  Serial.begin(9600);

}

void loop() {

  int movimento = digitalRead(pir);
  int luz = analogRead(ldr);

  Serial.println(luz);

  if (movimento == HIGH && luz < limiteLuz) {
    digitalWrite(led, HIGH);
  }
  else {
    digitalWrite(led, LOW);
  }

   Serial.print("Movimento: ");
  Serial.print(movimento);
  Serial.print(" | Luminosidade: ");
  Serial.print(luz);
  Serial.print(" | Limite: ");
  Serial.println(limiteLuz);
  
  delay(100);

}
SISTEMA 02

Estacionamento inteligente

Um sensor ultrassônico mede a distância até o veículo e avisa o motorista com o LED: apagado quando há espaço de sobra, piscando ao se aproximar e aceso fixo quando é hora de parar.

Como funciona

O sensor ultrassônico HC-SR04 mede continuamente a distância até o objeto à frente. Um potenciômetro permite ajustar, na hora, qual é a distância limite considerada segura — útil para calibrar o sistema para vagas de tamanhos diferentes.

  • Trig / Echo (pinos 9 e 10): sensor ultrassônico HC-SR04
  • Potenciômetro (pino A0): ajusta o limite de distância (10–150 cm)
  • LED (pino 13): indica a proximidade

// Pinos
const int trigPin = 9;
const int echoPin = 10;
const int led = 13;
const int pot = A0;

long duracao;
float distancia;
int valorPot;
float limite;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(led, OUTPUT);

  Serial.begin(9600);
}

void loop() {
  
    valorPot = analogRead(pot);

  // Converte para distância entre 10 e 50 cm
  limite = map(valorPot, 0, 1023, 10, 150);

  // Dispara o ultrassônico
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);

  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);

  digitalWrite(trigPin, LOW);

  // Mede o tempo
  duracao = pulseIn(echoPin, HIGH);

  // Calcula distância em cm
  distancia = duracao * 0.0343 / 2;

  Serial.print("Distancia: ");
  Serial.print(distancia);
  Serial.print(" cm   Limite: ");
  Serial.println(limite);

  // Lógica do desafio

  if (distancia > limite) {

    // Longe
    digitalWrite(led, LOW);

  } else if (distancia > limite / 2) {

    // Aproximando
    digitalWrite(led, HIGH);
    delay(300);
    digitalWrite(led, LOW);
    delay(300);

  } else {

    // Muito perto
    digitalWrite(led, HIGH);

  }

  delay(50);
}
SISTEMA 03

Monitoramento de estufa

Temperatura e umidade são lidas continuamente e três LEDs coloridos informam, à distância, se as plantas estão em condição ideal, com calor excessivo ou com pouca umidade.

Como funciona

O sensor de temperatura (TMP36) converte a tensão lida em graus Celsius, enquanto o sensor de umidade informa um valor de 0 a 1023. Combinando as duas leituras, o Arduino acende um dos três LEDs para indicar rapidamente a condição da estufa, sem precisar olhar números no monitor serial.

  • TMP36 (pino A0): sensor de temperatura
  • Sensor de umidade (pino A1): leitura analógica de 0 a 1023
  • LEDs (pinos 8, 10 e 12): verde, amarelo e vermelho

const int tempPin = A0;
const int umidadePin = A1;

const int verde = 8;
const int amarelo = 10;
const int vermelho = 12;

void setup() {

  Serial.begin(9600);

  pinMode(verde, OUTPUT);
  pinMode(amarelo, OUTPUT);
  pinMode(vermelho, OUTPUT);

}

void loop() {

  // TMP36
  int leituraTemp = analogRead(tempPin);

  float tensao = leituraTemp * (5.0 / 1023.0);

  float temperatura = (tensao - 0.5) * 100;

  // Sensor de umidade
  int umidade = analogRead(umidadePin);

  Serial.print("Temperatura: ");
  Serial.print(temperatura);

  Serial.print(" C   Umidade: ");
  Serial.println(umidade);

  digitalWrite(verde, LOW);
  digitalWrite(amarelo, LOW);
  digitalWrite(vermelho, LOW);

  bool temperaturaRuim = temperatura > 30 || temperatura < -10;

  bool umidadeBaixa = umidade < 50;

  if (!temperaturaRuim && !umidadeBaixa) {

    return digitalWrite(verde, HIGH);

  }

  if (temperaturaRuim && umidadeBaixa) {

    return digitalWrite(vermelho, HIGH);

  }

  if (umidadeBaixa || temperaturaRuim) {

    return digitalWrite(amarelo, HIGH);

  }

  delay(500);

}
